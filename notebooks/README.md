# Reproducible Research

The team's Jupyter notebooks are preserved here for those interested in recreating the research that led to the development of our portfolio generation system.

Some of the notebooks must be run in a particular order for proper functionality, provided below:

- Tom's Notebooks (1-5): Run these first, in order, to recreate the original data pull, initial data analysis, and feature generation.

- Pete's Notebooks (A-, B-, C-, and D- series): Run these after Tom's notebooks, starting with the A- series and proceeding in order through the B-, C-, and D- series.

 - To recreate the LSTM ensemble model's predictions for future volatility (over 30 trials), run the module 'model\_testing\_volatility.py' from the 'notebooks' directory. This module should only be attempted after running Tom's notebooks and Pete's notebooks (A-, B-, and C- series), as it relies on data files generated by those notebooks. *Note: This module takes approximately 10.5 hours to run on a modern laptop. To reduce runtime, change the NUM\_TRIALS global variable to a smaller number. Expect about 21 minutes per trial.

Kristine and Ryan's notebooks may be run independently of each other, but should be run after Tom's Notebooks (in order to have the SCF data available). They are also independent of Pete's notebooks.
